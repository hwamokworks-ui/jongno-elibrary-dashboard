# 종로구 전자도서관 소장목록 대시보드

서울특별시 종로구 전자도서관 소장목록 데이터를 시각화하는 Streamlit 대시보드입니다.

## 주요 기능

### 1. 종로구 상세 분석
- 구분/대분류/서명/저자/출판사 조건으로 데이터 필터링
- 자료 건수, 보유 권수 합계, 출판사·저자 수 등 요약 지표
- 대분류별 분포(도넛 차트), 출판사·저자 보유 건수 상위 N개 차트
- 출판사 × 대분류 히트맵, 보유 권수 분포 히스토그램
- 대분류별 평균 보유 권수 비교
- 필터링된 데이터 테이블 조회 및 CSV 다운로드

### 2. 자치구별 전자도서관 소장 비교
- 종로구·동대문구·동작구·서초구·영등포구 5개 자치구 데이터 비교
- 각 구별 자료 건수/출판사 수/저자 수, 대분류 비중, 평균 보유 수량 시각화
- 자치구마다 다른 원본 분류 체계를 하나의 통합 대분류 체계로 매핑하여 비교

## 기술 스택

- Python
- [Streamlit](https://streamlit.io/) — 웹 대시보드 프레임워크
- [pandas](https://pandas.pydata.org/) — 데이터 처리
- [Altair](https://altair-viz.github.io/) — 데이터 시각화

## 데이터

- `서울특별시 종로구_전자도서관소장목록_20250701.csv` (프로젝트 루트, cp949 인코딩)
- `data_unused/` 폴더의 타 자치구 비교용 CSV 4종 (동대문구, 동작구, 서초구, 영등포구)

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 자동으로 열리는 로컬 주소(기본 `http://localhost:8501`)에서 대시보드를 확인할 수 있습니다.
